# 表计安装点填表器 · 进展存档

> 给下一次对话用的交接说明。新会话先读这个文件，再动手。

## 一句话

把业务员的房间清单，按报账员从系统导出的「房产表计单据安装点导入」模板，生成可导入的 `.xls`。
Windows 桌面客户端，离线、不保存数据。

## 仓库与版本

- 仓库：`git@github.com:lzx-0827/form-filler.git`（SSH）
- 分支：`main`
- 最新提交：`daad005`（修正合并标题行被误判为表头）
- 安装包：`dist\表计安装点填表器.zip`（约 21.8 MB）

## 技术栈

- Python 3.13 + pywebview 6.2.1 + WebView2（pythonnet）
- Excel 写入：pywin32 驱动本机 Excel COM，保留模板字体、数字格式、数据验证
- 前端：原生 HTML/CSS/JS；ExcelJS 读 `.xlsx`，SheetJS 读 `.xls`
- 打包：PyInstaller `--onedir --noconsole`

## 功能现状

1. **模板**：`.xls/.xlsx` 都能读；表头按字段名找（房屋地址、楼宇名称等），列位置不写死；下拉选项从模板读（含命名范围）。
2. **房间清单**：`.xlsx`；按**数据格式**猜列，不依赖表头名称：
   - 楼栋：`1幢 / 1栋 / 1# / 北区3`
   - 单元：`A / B / A单元`
   - 楼层：`1F / 2层 / 1~30`
   - 房间号：`1-101 / 101 / 102室`
   - 横向门牌：有楼层列 + 右侧多列门牌
3. **解析设置**：默认自动解析；结果不对或解析失败时，可手动指定布局、表头行、楼栋列、单元列、房间号列 / 楼层列 / 门牌起始列。
4. **楼栋对应**：按栋号自动建议，用户确认；多解留空。
5. **地址**：`前缀 + 楼宇名称 + 单元号 + 门牌`；前缀必填。
6. **预览**：每页 100 行；支持按楼栋/楼层/搜索过滤；可批量设置安装点和三种后缀。
7. **导出**：`.xls` 走 COM 另存为，`.xlsx` 直接保存；房号 `01–09` 保持文本。

## 业务默认值

- 是否已开支 `否`；是否可接入 `是`；是否通过单元号楼层号房号生成地址 `否`
- 安装点默认 `厨房表`，地址含「别墅」自动 `别墅表`
- 楼层号取门牌末两位之前；房号取末两位

## 稳定性要点（别踩回去）

- **不要**给 `sys.stdout/stderr` 加空设备兜底：无控制台打包时会因 pywebview 报错刷屏而卡死。现在保持 `None`。
- 打包前必须关闭运行中的实例，否则 `_internal/assets` 可能为空，界面变裸 HTML。
- 单实例互斥：重复双击会聚焦已有窗口后退出。
- WebView2 必须带 `--disable-features=CalculateNativeWinOcclusion`，否则拖动窗口假死。
- 导出有全屏遮罩，防止重复点击开多个 Excel。
- 运行日志：`%TEMP%\meter-filler.log`

## 设计约束（用户反复强调）

- 模板决定一切：列位置、下拉、行数都按模板识别，不写死
- 导出格式必须和模板一模一样（字体、数字格式、下拉）
- 楼栋对应必须让用户确认，不能自己猜
- 房间表格式不统一，解析要按「数据长什么样」而不是表头名称
