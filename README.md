# 表计安装点填表器

把《房间编号.xlsx》展开成「房产表计单据安装点导入」表，写进用户提供的空模板，导出 `.xls`。

Windows 桌面客户端：独立窗口、原生另存为，不联网、不保存数据。

## 使用

1. 双击 `表计安装点填表器.exe` 打开窗口。
2. 上传空模板（`.xls` / `.xlsx`）。
3. 上传房间编号（`.xlsx`）。
4. 确认楼栋对应，填写项目地址前缀；预览每页 100 行，可翻页。
5. 点「导出 .xls」，选择保存位置。
6. 关闭窗口即退出。

## 填写规则

```
房屋地址 = 项目地址前缀 + 楼宇名称 + 单元号 + 门牌
```

| 字段 | 取值 |
|---|---|
| 房屋地址 | 上式；不含楼栋的小区楼宇名称为 `-` |
| 是否已开支 / 是否可接入 / 是否通过…生成地址 | 固定 `否` / `是` / `否` |
| 楼宇名称 | 用户确认，选项来自模板 |
| 安装点位置 | 默认 `厨房表`，可整批或单行改；地址含「别墅」自动 `别墅表` |
| 单元号 | `A-` / `B-` / 空，来自房间编号 |
| 单元后缀 / 楼层后缀 / 房号后缀 | 用户选择，选项来自模板 |
| 楼层号 | 门牌去掉末两位 |
| 房号 | 门牌末两位，`01–09` 保持文本 |

模板决定一切：列位置、列顺序、下拉选项、行数都按模板识别，不写死；导出不改模板的字体与数字格式。

## 目录结构

```
index.html            页面
assets/               样式、图标
src/core.js           模板识别、房间解析、地址拼接
src/app.js            界面逻辑
vendor/               WebView 内的 Excel 读写
desktop.py            桌面入口（pywebview + WebView2）
excel_export.py       Excel COM：写模板、读下拉选项
build_desktop.ps1     打包脚本
使用说明.txt            随包说明
scripts/              测试与造数据脚本
samples/              测试输出目录
```

## 开发

```powershell
pip install -r requirements.txt
npm install

python desktop.py                 # 开发模式直接开窗
python scripts/test_desktop_api.py  # 桌面 API 测试
.\build_desktop.ps1               # 打包 dist\表计安装点填表器.zip
```

## 限制

- 需要 Windows 10/11、本机 Excel（导出 `.xls` 时调用）、WebView2 运行时（Win11 自带）。
- 一次导出约 5–10 秒（1056 行）。
- 只支持桌面客户端；直接用浏览器打开 `index.html` 会提示使用 exe。
